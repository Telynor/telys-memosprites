# Tely's Memosprites

Standalone Foundry VTT v14 module for D&D 5e 5.x. Requires **Tely's Star Rail Ultimates** v3.13.6 or later. Install both modules and enable them in the same world.

On a character sheet, open **Memosprite**. A GM can enable the sprite, drop an Actor or Item onto its source slot, choose a portrait, configure up to five abilities and one of three resource displays, and place its frame over that character's combat HUD. Changes save automatically. Owners can summon or unsummon and use abilities; the GM can do both. The summon state and resource values are stored on the summoner Actor so every client sees the same state. The HUD appears while the parent module's party combat HUD is visible.

Dropping a source links its UUID and copies its name and portrait. It does not create a combatant or token. An Actor source's D&D 5e or Midi-QOL damage rolls are attributed to the summoned sprite's owner for HSR toughness, using the summoner's element and Break settings. An Item source has no separate actor: configure a damage formula on one of the sprite's abilities instead. Ability damage rolls appear in chat under the summoner and use HSR's existing toughness processing; use the chat card's normal Apply Damage control for HP damage. The GM can restore charges and adjust resource values in the tab. When the source is an Actor, the memosprite HP and maximum HP follow that Actor's sheet; the semicircular HP bar fills clockwise from empty at 0 to full at maximum HP. Heal or damage the source Actor to change memosprite HP. An Item source uses the tab's manual HP fields.

The module adds a tab beside the existing HSR sheet tabs without modifying the required module's files. **Open portrait editor** opens a larger circular crop preview; drag the image to position it, scroll over it to zoom, select an uploaded image, or drop an Actor or Item. Save Portrait applies the crop to the HUD and sheet preview. The **Combat HUD frame designer** uses the summoner's current HSR combat HUD layout. Drag and scale the portrait with its semicircular HP bar, HP value, resource, and ability row separately. Visibility checkboxes and **Remove from HUD / Restore to HUD** buttons let the GM choose which elements appear. **Show bottom character name on the HUD** controls the underlying summoner name label beneath the HP bar for this character's HUD, without changing the actor's actual name. The default tab icon is a small sprite emblem and the GM can upload another image.

An enabled Remembrance character gets a movable, resizable floating Summon button, shown for the player's selected main character or the GM's eligible characters. Click to summon or unsummon. Drag the button onto a Foundry hotbar slot to create a summon macro. Closing the button hides it on that user's client; **Show floating summon button now** in the character's Memosprite tab restores it.
